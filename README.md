# Strategisk trening – FINAL uten sjakk

Denne versjonen er laget for langvarig bruk på iPhone og PC. Sjakk er fjernet helt.

## Viktigste funksjoner
- Adaptiv progresjon per ferdighet
- Hoderegning: +, -, ×, ÷, prosent, brøk, estimasjon, kjederegning
- 60-sekundersmodus og Hard mode
- Tretrinns hint i matte: hint 1 → hint 2 → fasit + metode
- Hukommelse: sekvens, arbeidsminne og n-back
- Logikk: flere oppgavetyper, hint og forklaringer
- Reaksjon + Go/No-Go impulskontroll
- Observasjon: gjenkalling og finn endringen
- Selvkontrolløvelser
- Strategiske scenarioer med hint og forklaring
- Feilbank: feil lagres og kan repeteres senere
- Dagens adaptive økt
- Eksamenmodus
- Progresjon, feiltyper, rekorder og milepæler
- Backup eksport/import
- Focus mode
- PWA/offline-cache

## GitHub Pages
Erstatt filene i det eksisterende repoet med alle filene fra denne mappen. Vent på GitHub Pages, åpne siden i Safari, og lukk/åpne hjemskjerm-appen.

## Viktig
Progresjonen lagres lokalt i nettleseren. Eksporter backup av og til hvis du vil være sikker på å kunne flytte progresjonen.
